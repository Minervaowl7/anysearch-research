# 中文科技查新引用

用户给出格式时以其当前格式为准。用户要求“引用之”“用我习惯的格式”且未给新格式时，
采用以下逐字段格式；每个字段独占一行，不把整条文献压成一个长段落。
不确定的字段写“未核实”或“未标明”，不要补造作者、日期、刊期、页码或链接。

## 非专利文献

序号、标题：原文题名（必要时附中文译名）
作者：作者或机构
文献类型：期刊论文／技术白皮书／产品技术资料等
文献日期：文献自身标注日期；未标明则如实说明
公开记录：独立核实的公开时间与依据；无法核实则说明
来源：原文完整 URL
摘要：仅概括文献公开的技术内容，使用完整中文段落。

保留 DOI、报告号、卷期页码等已核实标识信息，可以独占一行补充。
外文原摘要需要整段中文翻译时，完整翻译实际取得且允许使用的摘要；
若只取得节选，明确标注“摘要节选译文”，不得冒充完整摘要。
未取得原摘要而根据正文编写时，标注“技术内容概述”，不要冒充原文摘要。

## 专利文献

序号、标题：专利名称
发明人：已核实发明人
申请人：已核实申请人
文献类型：发明专利申请／授权发明专利／实用新型等
公开号／公告号：准确标识号及文献种类代码
文献日期：该版本的公开／公告日期
公开记录：已核实公开事实；不要用申请日替代公开日
摘要：实际公开技术内容的客观中文表述。

专利条目不必另列裸 URL，但保留平台来源引用或可追溯标识。
“与查新点的对应关系／未公开特征”写在摘要之外，不混入客观摘要。
不要借任何固定模板删去用户所需的关键字段。
